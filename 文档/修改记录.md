# MaskFlow 修改记录

## v2.1.0 — 开源工程化版本（2026-08-21）

- 正式采用 AGPL-3.0，并补充第三方组件与 SAM 3 模型权重声明。
- 重写 README 首屏，加入点提示分割、控制台、图片管理和数据集导出截图。
- 修复 Production 模式示例密钥可通过校验的问题，禁止生产环境开启重置码回显和计费开发模式。
- SAM 内部鉴权改用常量时间比较；注册和修改密码统一要求至少 8 个字符。
- Docker Compose 默认仅绑定回环地址，MySQL/API 数据卷改为首次启动自动创建。
- SAM 服务默认启用内部密钥，Compose 增加健康检查，前端镜像改用 `npm ci`。
- 新增前后端 `.dockerignore`、GitHub Actions CI 和 Dependabot 配置。

## 2026-08-21

### 1. 忘记密码 / 密码找回

**问题**：登录页「忘记密码？」为无效链接，点击无反应。

**改动**：
- 前端登录页增加「获取重置码 → 设置新密码」完整流程（`AuthPage.vue`、`useMaskFlowApp.js`）
- 后端新增接口：
  - `POST /api/auth/forgot-password`：按邮箱生成 30 分钟有效重置码
  - `POST /api/auth/reset-password`：用重置码设置新密码并失效旧会话
- 当前部署未接邮件服务，开发环境 / `MASKFLOW_PASSWORD_RESET_INLINE=true` 时在页面内回显重置码
- `docker-compose.yml` 默认开启 `MASKFLOW_PASSWORD_RESET_INLINE=true`

### 2. 点提示（Point Prompt）SAM 分割

**能力**：在自动分割页与标注页支持正/负点击提示抠图。

**改动**：
- SAM 服务新增 `POST /api/segment/points`（`sam-inference`）
- API 代理：`/api/segment/points`、`/api/annotations/points`
- 前端共用点提示状态与请求逻辑；确认目标后保留多边形/框，清除提示点；可新建下一目标
- 检测类项目仍可同时保存 bbox + mask
- 推理侧修复：点坐标按「单目标多点」组织、掩码类型转换、请求串行化等稳定性问题

### 3. 分割边缘平滑

**问题**：掩膜边缘锯齿明显，圆形等目标贴边不干净。

**改动**（`sam-inference`）：
- 掩膜升采样改为三次插值 + 高斯软边
- 椭圆核形态学闭运算/开运算修边
- 轮廓点滑动平均后再轻度多边形简化
- 叠加预览与导出几何共用同一套精炼逻辑

### 4. 标注画布缩放修复

**问题**：缩放比例超过 100% 后画面不再变大（看起来只能放到适配尺寸）。

**改动**：
- 去掉画布 `max-width/max-height: 100%` 对显式缩放尺寸的限制
- 放大后可在画布区域内滚动查看
- 缩放范围仍为 25%–300%；「适配」回到窗口适合尺寸
