# MaskFlow 修改记录

## 2026-08-21

### 1. 忘记密码 / 密码找回

**问题**：登录页「忘记密码？」为无效链接，点击无反应。

**改动**：
- 前端登录页增加「获取重置码 → 设置新密码」完整流程（`AuthPage.vue`、`useMaskFlowApp.js`）
- 后端新增接口：
  - `POST /api/auth/forgot-password`：按邮箱生成 30 分钟有效重置码
  - `POST /api/auth/reset-password`：用重置码设置新密码并失效旧会话
- 当前部署未接邮件服务，开发环境 / `MASKFLOW_PASSWORD_RESET_INLINE=true` 时在页面内回显重置码
- `docker-compose.yml` 默认开启 `MASKFLOW_PASSWORD_RESET_INLINE=true`

### 2. 点提示（Point Prompt）SAM 分割

**能力**：在自动分割页与标注页支持正/负点击提示抠图。

**改动**：
- SAM 服务新增 `POST /api/segment/points`（`sam-inference`）
- API 代理：`/api/segment/points`、`/api/annotations/points`
- 前端共用点提示状态与请求逻辑；确认目标后保留多边形/框，清除提示点；可新建下一目标
- 检测类项目仍可同时保存 bbox + mask
- 推理侧修复：点坐标按「单目标多点」组织、掩码类型转换、请求串行化等稳定性问题
